Pipeline application · PhysioNet 2019 study workflow

Datasource, ingestion, and validation

Datasource

PhysioNet/Computing in Cardiology Challenge 2019 early-sepsis dataset. One pipe-separated PSV file per patient, with hourly observations and a SepsisLabel target. Clinical data are external and are not bundled.

The known schema has 39 clinical/context inputs. Optional or absent input fields are allowed and remain missing for fit-only imputation.

Field-level checks

  • Reject duplicate column names.
  • Require numeric, non-missing SepsisLabel values in {0, 1}.
  • Require present known clinical/context fields to be numeric where observed.
  • When ICULOS is present, require numeric values increasing by one row; never use it as a predictor.

No physiologic range validation, unit normalization, or outlier correction is applied. Without ICULOS, hourly continuity is assumed from row order.

Processing

Files are discovered by *.psv and sorted by filename. Each file is parsed with the pipe delimiter and its filename stem becomes the patient key. Cohort construction uses rows 0–5 as input, a bounded outcome horizon, stratified fit/validation/test partitions, and fit-only preprocessing.
